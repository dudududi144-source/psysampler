# PSY LOOPER - Architecture Documentation

## Overview

PSY LOOPER is the most advanced looper in the PSY family with 200+ features.

## Core Components

- LooperDevice - Main device (PsyDevice contract)
- LoopAnalyzer - Loop analysis and slicing
- LoopGenerator - Generate 8 loop types
- SliceEngine - Slice playback engine
- SliceBank - 8 loop banks
- AudioGraph - 8 buses with FX
- FXChain - 12 effect types
- Determinism - Seeded operations
- MIDIIntegration - Full MIDI support
- AudioWorklets - High-performance DSP

## Features

- 8 Loop Banks
- ML-powered loop classification
- Multi-band transient detection
- 8 loop generation types
- 12 advanced FX
- MIDI integration
- Deterministic output
- 1000+ tests
