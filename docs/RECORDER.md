# PSY LOOPER - Recorder Documentation

## Overview

PSY LOOPER has live recording and overdub capabilities.

## Live Recording

### Recording a Loop

1. Click 'Record' button
2. Play your instrument
3. Click 'Stop' when done
4. Loop is captured and analyzed

### Recording Quality

- Format: WebM (Opus)
- Sample rate: 48kHz
- Channels: Stereo
- Automatic conversion to WAV

## Overdub

### Adding Layers

1. Load existing loop
2. Click 'Overdub' button
3. Record new layer
4. Layers are mixed automatically

### Layer Management

- Unlimited layers
- Each layer stored separately
- Undo/Redo support (100 steps)

## Undo/Redo

- 100 steps of undo/redo
- Perfect for experimenting
- Non-destructive

## Export

Recorded loops can be exported as:

- WAV (16/24/32-bit)
- AIFF
- MIDI (slice triggers)

## Integration with Slicer

Recorded loops are automatically:

- Analyzed for tempo and key
- Sliced at transients
- Classified by type

## Usage Tips

1. Use a metronome for consistent timing
2. Record in a quiet environment
3. Use overdub for complex arrangements
4. Export regularly to save your work
