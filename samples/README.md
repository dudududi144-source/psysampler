## Usage

1. Drop any WAV file onto the file drop area
2. Or click "Load Loop" button
3. The analyzer will automatically detect:
   - Tempo
   - Key
   - Loop type
   - Slice points

## File Format

- Format: WAV (PCM)
- Sample Rate: 44.1kHz or 48kHz
- Bit Depth: 16-bit or 24-bit
- Channels: Mono or Stereo

## Creating Your Own Samples

Use the Loop Generator to create new loops:

1. Select loop type (melodic, rhythmic, etc.)
2. Set BPM, key, scale, bars
3. Click "Generate Loop"
4. Export as WAV if needed
