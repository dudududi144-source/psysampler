# Contributing to PSY LOOPER

## Getting Started

1. Fork the repository
2. Create a feature branch
3. Make your changes
4. Run tests
5. Submit a pull request

## Development Setup

1. Clone the repository
2. Install dependencies: bun install
3. Run development server: bun run dev
4. Run tests: bun test
5. Run linter: bun run lint

## Code Style

- Use TypeScript for all new code
- Follow existing code patterns
- Add tests for all new features
- Update documentation

## Testing Requirements

- All new features must have tests
- Deterministic operations must be tested for byte-identical output
- Audio quality changes must include quality metrics
- Performance changes must include benchmarks

## Pull Request Process

1. Update README.md if needed
2. Add tests for new functionality
3. Ensure all tests pass
4. Update CHANGELOG.md
5. Submit PR with clear description
