## Usage

1. Open PSY LOOPER: https://dudududi144-source.github.io/psysampler/
2. Use the **Loop Library** panel to click and load any loop
3. Or drag & drop any WAV file onto the app
4. The analyzer auto-detects slices, tempo, and type

- Sample rate: 44,100 Hz
- Bit depth: 16-bit
